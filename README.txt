STUDENT TASK MANAGER

Open index.html in a modern browser. No installation or internet is required.

Features: add tasks, mark complete/pending, delete, filter, task counts,
empty-input validation, daily study tips, and browser local storage.

Validation rejects blank/whitespace-only input, names longer than 200
characters, and duplicate names (ignoring case and extra whitespace,
including completed tasks). Names are trimmed and repeated spaces are
collapsed. Errors are shown beside the form and rechecked as you type.
Saved tasks are checked for valid fields, unique IDs, and title length.

Tasks are saved in the current browser when storage is available. Private
browsing, clearing site data, or moving the files may affect saved tasks.
Daily tips rotate by local calendar date and work offline.

Files: index.html, style.css, script.js.
If using your original "index (2).html", keep style.css and script.js in
the same folder. The supplied script also works with your original HTML.
